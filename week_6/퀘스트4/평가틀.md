# 📸 Day On(데이온) 인스타그램 인플루언서 평가 틀

> **대상 카페**: Day On — **서울 서대문구 연희동** 주택가 골목,
> 견과(너트) 테마, 걸어서 오는 동네 주민 타겟
> (기획서: `week_5/퀘스트6/my_cafe.md`)

---

## 0. 대전제 — 왜 대형 인플루언서가 답이 아닌가

Day On은 **도보권 손님으로 먹고사는 카페**다. 운영 데이터가 그렇게 말한다.

- 주차 불가 (2점 리뷰: *"주차가 아예 안 돼요. 골목이라 차 가져가면 고생합니다"*)
- 주말 매장 체류 71.5% → **이미 좌석 포화** (2점 리뷰: *"주말에 자리가 없어서 그냥 돌아왔어요"*)

즉 **광역에서 손님을 끌어오는 마케팅은 낭비이거나 역효과**다.
팔로워 10만 명 중 우리 동네 사람이 몇 명이냐가 전부다.

→ **팔로워 수보다 '지역 겹침'과 '인게이지먼트율'이 우선한다.**
→ 주말을 더 붐비게 만드는 콘텐츠(주말 나들이 코스 등)는 피하고, **평일·아침·퇴근길** 소구가 맞다.

---

## 1. 찾아야 할 계정의 3가지 결

| 결 | 왜 | 검색 실마리 |
|---|---|---|
| **① 동네·골목 로컬 계정** | 우리 손님은 걸어서 온다. 지역 겹침이 곧 전환율 | **연희동 상권 지명 태그** (아래 참조) — 가장 중요 |
| **② 디저트·베이커리 전문** | 피칸파이가 재방문 이유. 견과 테마와 직결 | `#디저트맛집` `#파이맛집` `#수제디저트` `#베이커리카페` |
| **③ 식물·자연주의 공간 취향** | 인테리어가 차별점 (리뷰: *"식물 상태 보면 사장님 정성이 보여요"*) | `#분위기좋은카페` `#플랜테리어` `#우드인테리어` |
| **④ 골목 산책·로컬 라이프 계정** | 주말 유입원. 단, 좌석 포화라 **평일·아침 소구로만** | `#연희동` `#연희동골목` `#동네산책` `#로컬여행` |

### 🔍 연희동 상권 검색 태그 (우선순위 순)

**1순위 — 핵심 상권 (도보권 = 지역점수 25점)**
`#연희동카페` `#연희동맛집` `#연희동디저트` `#연희동베이커리` `#연희동골목`

**2순위 — 인접 상권 (지역점수 15점)**
`#연남동카페` `#가좌역카페` `#홍제동카페` `#신촌카페` `#서대문카페`

**3순위 — 같은 시·구 (지역점수 8점)**
`#서대문구카페` `#서대문구맛집`

**⚠️ 주의 — `#홍대카페` `#연남동카페`(관광 유입분)**
홍대·연남동은 **광역 관광 상권**이다. 유동인구·관광객으로 먹는 곳이고, 거기서 오는 손님은 대중교통으로 이동하는 원거리 손님이다.
Day On은 주민 재방문으로 먹는 카페다. 홍대·연남 중심 계정은 **팔로워가 커도 지역점수를 8점 이하로** 매기고 우선순위를 낮춘다.
(연남동은 연희동과 붙어 있어 **생활권 계정이면 15점**, 관광 콘텐츠 위주면 8점으로 갈라서 본다.)

## 2. 기록할 지표

| 항목 | 어디서 | 비고 |
|---|---|---|
| 팔로워 수 | 프로필 상단 | |
| 최근 게시물 9개의 좋아요 | 게시물별 | 광고·협찬 게시물은 제외하고 세는 게 정확 |
| 최근 게시물 9개의 댓글 | 게시물별 | |
| 활동 지역 | 프로필 소개·게시물 위치 태그 | **가장 중요** |
| 콘텐츠 결 | 피드 전반 | 위 3가지 결 중 무엇인지 |

**인게이지먼트율(ER)** = (평균 좋아요 + 평균 댓글) ÷ 팔로워 수 × 100

---

## 3. 점수표 (100점)

| 항목 | 배점 | 기준 |
|---|---:|---|
| **인게이지먼트율** | 40 | 6%↑ = 40 / 4~6% = 32 / 3~4% = 24 / 2~3% = 12 / 2%↓ = 0 |
| **지역 적합도** | 25 | 같은 동·도보권 = 25 / 인접 상권 = 15 / 같은 시·구 = 8 / 무관·전국 = 0 |
| **콘텐츠 결** | 20 | 디저트·베이커리 or 자연주의 공간 = 20 / 일반 카페 = 12 / 그 외 = 4 |
| **팔로워 규모 적정성** | 15 | 5천~5만 = 15 / 1천~5천 = 8 / 5만~10만 = 8 / 그 외 = 3 |

### 판정
- **80점 이상** — 1순위. 바로 접촉
- **60~79점** — 2순위. 여력 되면 접촉
- **60점 미만** — 보류

### 🚩 위험 신호 (점수와 무관하게 거른다)
- **팔로워는 많은데 ER 1% 미만** → 팔로워 구매 의심
- 댓글이 전부 이모지 한 개짜리 → 품앗이·봇 댓글 의심
- 협찬 게시물이 피드의 절반 이상 → 광고판. 신뢰도 낮음
- **주말 나들이·드라이브 코스 위주** → 우리에겐 역효과 (좌석 포화 악화)

## 4. 규모 구간별 쓰임새

| 구간 | 성격 | Day On에서의 용도 |
|---|---|---|
| 1천~5천 (나노) | 진짜 동네 사람 | **재방문 단골화**. ER이 가장 높고 단가가 싸다 |
| 5천~5만 (마이크로) | 지역 맛집·디저트 계정 | **핵심 구간.** 도달과 신뢰의 균형 |
| 5만~10만 | 광역 카페투어 | 신메뉴 출시 등 **이벤트성 1회** 정도 |
| 10만 이상 | 전국구 | **하지 말 것.** 도보권 밖 유입 = 주차 불만 + 좌석 포화 |

## 5. 작업 순서

1. `인플루언서_후보.csv` 에 계정별로 값을 채운다 (좋아요·댓글 9개씩)
2. `node score.js` 실행 → ER 계산 + 점수 + 순위가 `인플루언서_평가결과.csv` 로 나온다
3. 80점 이상부터 접촉

> 지역 점수(`지역적합도`)와 콘텐츠 점수(`콘텐츠결`)는 사람이 판단해서 CSV에 직접 적는다.
> 나머지(ER·팔로워 점수·총점·순위)는 스크립트가 계산한다.
