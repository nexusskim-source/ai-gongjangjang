카페 기획서(`week_5/퀘스트6/my_cafe.md`) 기반으로 구축한 운영 DB를 분석한 결과물이다.

- **원본 데이터**: Supabase `cafe_*` 테이블 7개 (메뉴 / 일별매출 / 메뉴별판매량 / 리뷰 / 재고 / 발주 / 방문객)

## 주요 발견

**1. 매출 5,464만원 / 일평균 62.8만원 / 객단가 9,148원, 평균 마진율 65.0%**

**2. 요일 매출 차이는 곧 손님 수 차이다.**
객단가는 요일과 무관하게 8,908~9,356원으로 거의 같다(편차 5%). 반면 손님 수는 월 53.2명 ~ 토 117.1명으로 2.2배 차이. 즉 매출 격차는 전적으로 방문객 수에서 온다.

**3. 주말은 이미 포화 상태다.**
토·일 테이크아웃 비중이 28.5%로 평일(41~43%)보다 훨씬 낮다 = 매장이 꽉 찬다.
실제로 "주말에 자리가 없어서 그냥 돌아왔어요"(카카오맵 2점) 리뷰가 있다.
→ **주말 유입을 늘리는 마케팅은 역효과**, 약한 요일(월·화·수)로 수요를 분산해야 한다.

**4. 더울수록 시그니처가 안 팔린다.**
폭염일 매출은 맑은 날 대비 **-18.3%**. 16개 메뉴 중 폭염일에 판매가 오르는 건 자몽에이드(+25%)와 헤이즐넛 콜드브루(+21%) 둘뿐이고, 간판 세트(너츠라떼+피칸파이)는 **-31.9%**로 가장 크게 무너진다.
→ 견과 테마 × 아이스 음료 교집합이 비어 있다. **아이스 견과 음료 신메뉴가 필요하다.**

**5. 논커피는 매출 비중 꼴찌(8.7%)인데 마진율은 1위(69.5%).**
가장 안 파는데 가장 남는 칸 = 성장 여지가 가장 크다.

**6. 재고 20품목 중 7개가 안전재고 이하**로 발주가 필요하다. 특히 피칸파이 시트(22/25개)는 이미 부족하고, 피칸(생)도 여유가 0.2kg뿐이라 견과 메뉴를 늘리면 바로 품절 위험이 있다.

## 고객의 소리 (리뷰 60건)

평균 4.48점. 5점 37건 / 4점 17건 / 3점 4건 / 2점 2건. 채널별로는 네이버 4.91점, 인스타 4.71점, 구글 4.25점, 카카오맵 4.05점.

**칭찬받는 것 = 시그니처와 공간.**
너츠라떼는 8회 언급에 평균 **5.00점(불만 0건)**, 간판 세트도 6회 언급에 5.00점. 견과 테마가 실제로 먹히고 있다. 공간에 대한 반응도 좋다 — "골목에 이런 데가 있는 줄 몰랐어요", "식물 상태 보면 사장님 정성이 보여요".

**불만은 메뉴가 아니라 공간·가격에 몰려 있다** (`10_고객의소리_불만사항.csv`):
- **좌석 부족** — "주말에 자리가 없어서 그냥 돌아왔어요" (2점) ← 매출 직접 손실
- **주차 불가** — "골목이라 차 가져가면 고생합니다" (2점) ← 상권 특성상 해결 난이도 높음
- **가격 저항** — 햄치즈 샌드위치 "8,500원은 살짝 비싼 느낌"(3점), 피칸파이 "5,000원이면 조금 비싼 듯"(3점)
- **비시그니처 메뉴의 평범함** — 카페라떼 3.00점, 자몽에이드 3.50점, 햄치즈 샌드위치 3.50점
  → "라떼는 그냥 그랬어요. **시그니처 메뉴를 시키는 게 맞는 것 같습니다**"

즉 **시그니처는 강하고 일반 메뉴는 약하다.** 판매 데이터(햄치즈 샌드위치 -5.7% 역성장, 제철 과일 티 판매 최하위)와도 일치한다.
