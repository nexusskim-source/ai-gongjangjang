# Quick Dinner Recipe (15분 저녁 레시피 + fal.ai 썸네일)

**15분 이내**에 완성 가능한 저녁 레시피를 만들고, fal.ai로 그 요리의 실제 음식 사진(썸네일)을
생성해 **레시피 마크다운 최상단**에 삽입한 뒤 파일로 저장하는 스킬이다.
채팅에도 레시피 전문을 함께 보여준다.

## 핵심 동작 요약

1. 요청 파악 → 2. 15분 레시피 설계 → 3. fal.ai 썸네일 생성 → 4. 썸네일이 맨 위에 있는 마크다운 저장 → 5. **자기완결형 HTML 한 파일 생성** → 6. 채팅 출력 + 저장 경로 안내

## 1. 요청 파악

사용자 요청은 보통 두 갈래다. 둘 다 지원한다.

- **자유 요청형**: "맛있는 저녁 추천", "얼큰한 국물 저녁", "혼밥 저녁 15분" 등
  먹고 싶은 것/기분/상황에 맞춰 알아서 인기 있는 15분 메뉴를 제안한다.
- **보유 재료형**: "계란이랑 김치 있는데 저녁 뭐 해먹지" 등
  가진 재료를 최대한 활용하는 메뉴를 만든다. 기본 조미료(소금·후추·기름·간장·설탕 등)와
  밥·라면·파스타면 같은 흔한 상비 재료는 있다고 가정해도 된다.

특별한 지정이 없으면 **레시피 1개**를 만든다(썸네일 1장 = fal.ai 호출 1회).
"여러 개 추천"을 원하면 2~3개까지 만들고, 각 레시피마다 썸네일을 따로 생성한다.

## 2. 15분 레시피 설계

가장 중요한 제약은 **실제로 15분 안에 완성 가능**해야 한다는 것이다.
- 총 소요시간(손질+조리)이 15분을 넘지 않게 현실적으로 설계한다. 오래 끓이거나 재우는 요리는 피한다.
- 조리 단계는 3~6단계로 간결하게. 병렬로 할 수 있는 작업(물 끓이는 동안 재료 손질 등)은 그렇게 안내한다.
- 요리 이름·설명·재료·조리법은 **한국어**로 쓴다.
- 분량은 기본 1인분, 요청 시 조정한다.

## 3. fal.ai 썸네일 생성

`scripts/gen_thumbnail.py`를 실행해 요리 사진을 만든다. 이미지 프롬프트는 **영어**로 쓴다
(flux 모델은 영어에서 품질이 가장 좋다). 아래 요소를 담아 먹음직스럽게 묘사한다.

- 요리 이름과 핵심 재료 (예: "kimchi fried rice with a fried egg on top")
- 플레이팅/그릇, 촬영 각도(top-down 또는 45-degree), 조명(warm cozy lighting)
- 스타일 키워드: `professional food photography, appetizing, high detail`
- 글자·워터마크가 들어가지 않게 프롬프트에 텍스트 요구는 넣지 않는다.

실행 명령 (경로에 한글이 있어도 `py`로 정상 동작한다):

```bash
py "C:/수경_ai공장장/.claude/skills/quick-dinner-recipe/scripts/gen_thumbnail.py" \
  --prompt "kimchi fried rice with a fried egg on top, in a black bowl, top-down, professional food photography, warm cozy lighting, appetizing, high detail" \
  --out "C:/수경_ai공장장/quick-dinner-recipes/2026-07-04-김치볶음밥/thumb.jpg"
```

- 스크립트는 성공 시 **마지막 줄에 저장된 이미지의 절대경로**를 출력한다.
- API 키는 스크립트 폴더의 `fal_key.txt`에서 자동으로 읽는다(별도 설정 불필요).
- 실패하면(HTTP 오류 등) 에러 메시지를 그대로 사용자에게 알리고, 썸네일 없이라도 레시피는 저장한다.

## 4. 마크다운 저장 (핵심 동작 — 항상 수행)

- **저장 폴더**: `C:/수경_ai공장장/quick-dinner-recipes/{YYYY-MM-DD}-{메뉴이름}/`
  (레시피별로 폴더를 하나씩. 썸네일과 md를 같은 폴더에 둔다.)
- **파일**: 같은 폴더에 `thumb.jpg`(썸네일)와 `recipe.md`(레시피)를 저장한다.
- **썸네일은 반드시 문서 최상단**에 들어간다. md와 이미지가 같은 폴더이므로 **상대경로**로 참조해
  마크다운 미리보기에서 그림이 바로 보이게 한다: `![메뉴이름](thumb.jpg)`

`recipe.md` 형식 템플릿:

```markdown
![{메뉴 이름}](thumb.jpg)

# 🍽️ {메뉴 이름}

> {군침 도는 한 줄 소개}

⏱️ **총 15분**  ·  👤 **1인분**  ·  🔥 **난이도: 쉬움**

## 🧺 재료
- {재료} {분량}
- ...
  *(가진 재료는 ✅, 추가로 필요한 재료는 🛒 표시)*

## 👩‍🍳 만드는 법
1. {단계}
2. ...

## 💡 팁
- {실패 없이 맛있게 만드는 팁 1~2개}

---
*생성일: {YYYY-MM-DD} · 썸네일: fal.ai (flux/schnell)*
```

## 5. HTML 한 파일 만들기 (항상 수행 — 이미지+레시피를 한 파일로 보기)

`recipe.md`와 `thumb.jpg`를 합쳐 **이미지가 파일 안에 박힌 자기완결형 `recipe.html`**을 만든다.
사용자가 파일 하나만 열면 사진(맨 위)과 레시피가 한 화면에 예쁘게 보인다.

```bash
py "C:/수경_ai공장장/.claude/skills/quick-dinner-recipe/scripts/build_recipe_html.py" \
  --md  "C:/수경_ai공장장/quick-dinner-recipes/2026-07-04-김치볶음밥/recipe.md" \
  --img "C:/수경_ai공장장/quick-dinner-recipes/2026-07-04-김치볶음밥/thumb.jpg" \
  --out "C:/수경_ai공장장/quick-dinner-recipes/2026-07-04-김치볶음밥/recipe.html"
```

- 이미지를 base64로 내장하므로 HTML 파일 하나만 있으면 어디서든 그대로 보인다.
- 생성 후 사용자가 바로 볼 수 있게 브라우저로 열어준다(Windows):
  `Start-Process "…/recipe.html"` (PowerShell). 원하면 이 단계는 생략 가능.

## 6. 마무리

- 저장 후 사용자에게 **저장된 폴더 경로와 `recipe.html` 경로**를 알려준다.
- 채팅에도 레시피 전문(재료·조리법·팁)을 함께 출력한다. 썸네일과 HTML은 파일로 저장됐음을 언급한다.

## 원칙

- 15분 제약을 최우선으로 지킨다. 지키기 어려우면 더 간단한 메뉴로 바꾼다.
- 사진 프롬프트는 실제 만들 요리와 일치시킨다(엉뚱한 요리 사진이 나오지 않게).
- 저장은 요청이 없어도 항상 수행한다(이 스킬의 핵심 산출물).
- fal.ai 호출은 비용이 드니 기본 1장만 생성하고, 다중 레시피 요청일 때만 여러 장 만든다.
