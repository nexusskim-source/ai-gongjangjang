# Google 평점 맛집·카페 파인더

지역과 키워드를 받아 **Google Places API**로 검색하고, **리뷰수 하한으로 신뢰도를 거른 뒤 평점순**으로 정리해 채팅에 표로 보여준다.

## 왜 이렇게 하는가
평점만으로 줄 세우면 "리뷰 3개짜리 5.0점"이 1등이 되는 함정이 있다. 그래서 기본적으로 **리뷰 30개 이상**인 곳만 후보로 두고 평점 내림차순(동점이면 리뷰수)으로 정렬한다. 이게 사람들이 실제로 "믿고 가는 집"에 가깝다.

---

## ① API 키 발급 (최초 1회만)

키 파일이 없으면 스크립트가 안내 메시지를 내며 멈춘다. 사용자에게 아래를 안내한다.

키 파일 경로: `.claude/skills/google-rating-finder/google_places_key.txt`

**발급 절차 (5~10분, 무료 크레딧 월 $200 제공):**
1. https://console.cloud.google.com 접속 → 구글 계정 로그인
2. 상단에서 **새 프로젝트** 생성 (이름 아무거나, 예: `cafe-finder`)
3. 좌측 메뉴 **API 및 서비스 → 라이브러리** → **"Places API (New)"** 검색 후 **사용 설정**
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키** → 생성된 키 복사
5. 결제 사용 설정(무료 크레딧 범위 내라 실제 청구는 거의 없음). 프로젝트에 결제 계정 연결이 안 되어 있으면 API가 거부되므로 **결제 계정 연결**까지 해야 한다.
6. 복사한 키를 위 `google_places_key.txt` 파일에 **한 줄로** 저장한다.

> 보안: 키 값을 채팅에 붙여넣지 말고 파일에만 저장하라고 안내한다. 이 파일은 커밋되면 안 된다(아래 gitignore 참고).

키를 저장했는지 사용자에게 확인한 뒤 다음 단계로 넘어간다.

## ② 검색 실행

사용자 요청에서 **지역 + 키워드**를 하나의 검색어로 조합해 스크립트에 넘긴다.
예: "강남역 근처 조용한 카페" → `"강남역 조용한 카페"`

이 PC의 파이썬은 스토어 스텁이 아닌 전체 경로를 써야 한다:

```bash
"C:/Users/김수경/AppData/Local/Programs/Python/Python312/python.exe" \
  ".claude/skills/google-rating-finder/scripts/find_places.py" \
  "강남역 브런치 카페"
```

**옵션 (필요할 때만):**
- `--min-reviews N` — 리뷰수 하한 (기본 30). "숨은 신상"까지 보고 싶다면 낮추고, 확실한 검증만 원하면 100 등으로 올린다.
- `--top N` — 상위 몇 곳 (기본 10)
- `--open-now` — 지금 영업중인 곳만. 사용자가 "지금 문 연"이라고 하면 붙인다.

스크립트는 이미 마크다운 표를 출력하므로, **그 표를 그대로 사용자에게 보여주면 된다.** 순위·이름(지도링크)·평점·리뷰수·종류·가격대·영업여부·주소가 들어있다.

## ③ 결과 제시

스크립트 출력 표를 보여준 뒤, 사용자 맥락에 맞춰 **한두 줄 코멘트**를 덧붙이면 좋다.
- 예: "1위 ○○는 리뷰도 400개 넘게 쌓인 확실한 검증 맛집이고, 3위 △△는 리뷰 대비 평점이 높아 '요즘 뜨는 곳' 느낌이에요."
- 사용자가 "지금 문 연 곳만", "너무 비싼 데 말고", "리뷰 많은 확실한 데만" 같은 조건을 주면 옵션을 바꿔 다시 실행한다.

원본 표 외에 사용자가 파일 저장을 원하면 스크립트 출력을 `.md`로 저장해준다(기본은 채팅 표로만).

## 참고
- 결과가 비면: 검색어를 넓히거나(지역만, 또는 키워드만) 다른 표현으로 재시도.
- `[API 오류 403/PERMISSION_DENIED]`: Places API(New) 미활성 또는 결제 계정 미연결. ①-3, ①-5 재확인.
- `[API 오류 400]`: 요청 형식 문제 — 대개 스크립트 수정 없이 검색어만 단순화하면 해결.
- 리뷰 하한 때문에 후보가 0곳이면 스크립트가 자동으로 하한 없이 전체를 평점순으로 보여준다(경고 문구 표시).
